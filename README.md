# consolecheat Codes

Unlimited-Use-Codes für kostenlose PSN-Avatare und Gratis-DLCs. Gleiches Erscheinungsbild wie die anderen consolecheat-Seiten. Keine Werbung, keine Affiliate-Links, keine Einmal-Codes.

[codes.consolecheat.com](https://codes.consolecheat.com)

## Codes pflegen

Neue Codes nur in [src/data/codes.ts](src/data/codes.ts) eintragen, wenn sie mehrfach einlösbar sind und eine öffentliche Quelle haben. Aktuelle Pakete bekommen `era: "2026"`. Ältere Jahre bleiben in der Liste, aber getrennt. Ein Gratis-DLC kommt in dieselbe Liste mit `kind: "dlc"`.

## Lokal

```bash
npm install
npm run dev
```
