# consolecheat Codes

Unlimited-Use-Codes für kostenlose PSN-Avatare und Gratis-DLCs. Gleiches Erscheinungsbild wie die anderen consolecheat-Seiten. Keine Werbung, keine Affiliate-Links, keine Einmal-Codes.

Geplant als [codes.consolecheat.com](https://codes.consolecheat.com).

## Codes pflegen

Neue Codes nur in [src/data/codes.ts](src/data/codes.ts) eintragen, wenn sie mehrfach einlösbar sind und eine öffentliche Quelle haben. Abgelaufene Pakete rausnehmen. Ein Gratis-DLC kommt in dieselbe Liste mit `kind: "dlc"`.

## Mail

Adressen liegen in der Tabelle `code_subscribers`. Die Seite zeigt die Liste nicht an und verschickt selbst keine Werbung. Versand neuer Codes machst du aus dieser Tabelle. Austragen geht über dieselbe Adresse auf der Seite.

## Lokal

```bash
npm install
npm run dev
```
